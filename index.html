Anthropic Claude Integration

Let Claude direct your narrative. Without surrendering control.

Direct integration via the official Anthropic Messages API Python SDK (anthropic>=0.87.0 via anthropic_text_route.py). Your API credentials stay sealed in Windows Credential Manager under DPAPI encryption.

anthropic_text_route.py · API Configuration JSON 
{
  "editorial_director": {
    "provider": "anthropic",
    "model": "claude-3-5-sonnet-20241022",
    "context_window": "200_000_tokens",
    "thinking_budget": 8000,
    "output_format": "strict_json_schema",
    "temperature": 0.2,
    "client_security": {
      "key_storage": "windows_dpapi",
      "telemetry": "zero_retention"
    }
  }
}

Zero cloud middleman. Direct HTTPS socket from Windows desktop to api.anthropic.com/v1/messages.

LEVEL 1 · ASK

Research & Entity Verification (Read-Only)

Claude reads multi-chapter raw manuscripts, extracts historical facts, flags timeline contradictions, and establishes character bibles without modifying active project files.

LEVEL 2 · REVISE

Spoken Cadence Scripting (Interactive Diff)

Transforms raw prose into documentary narration. Enhances dramatic hook density and formats micro-pauses. Delivers revisions as visual diffs requiring explicit creator approval.

LEVEL 3 · DIRECTOR

Timeline Scene Assembly (Structured JSON)

Emits strictly validated JSON schemas specifying camera angles, motion prompts, and audio ducking cues. Directly drives the local FFmpeg rendering pipeline.
